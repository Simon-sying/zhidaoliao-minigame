# 《知道了！》产品决策说明（PM 视角）

本文记录关键产品判断与取舍，便于后续迭代时“知道为什么这么做”，而不只是看到代码。

## 1. 一句话定位

**一款让人“每天愿意回来、答错也不挫败”的轻量知识答题小游戏**：用温和的即时反馈和“又知道一点”的成长感做留存，用每日排名挑战做竞争与传播，用**用户主动触发的激励视频**做变现。

- 核心情绪资产：答对「知道了！」、答错「原来如此！」、连对「又知道一点！」——**把“答错”从负罪感改写成获得感**。
- 不做沉重的知识焦虑、不做 PVP 对抗压力、不做金币商城养成，保持“小游戏”该有的轻。

## 2. 目标用户与场景

- 泛大众，碎片时间（通勤、排队、睡前）想“轻松学点有用的东西”；
- 家庭场景：家长和孩子一起答（题库含 `ageLevel:'child'` 与安全/身体/金钱基础认知）；
- 愿意分享“我今天排第几 / 我又知道了什么”，但不喜欢被强制拉人。

## 3. 双玩法为何这样分工

| 玩法 | 心理任务 | 商业角色 |
| --- | --- | --- |
| 休闲刷题（无限答、答错继续、每题有解析记忆点） | 低压力获取知识、刷时长与熟练度、喂养掌握度 | 承载**主动型广告**（提示、阶段性知识总结），攒错题/收藏/掌握度 |
| 每日排名挑战（全用户同题、10 题答错即止、计分排名） | 制造确定性的“每日一次仪式感”和公平竞争 | 承载**失败再看广告再战**，并驱动分享拉新与次日回访 |

确定性每日题（按日期种子生成，全天全用户同一套、云端可复核）是公平排行的地基：没有随机差异，赢了是实力，且云端能用同一份题库重放校验。

## 4. 变现设计与克制原则

- 只做**激励视频**，且**全部由用户主动点击**：失败再战、知识总结、要提示。不做开屏、不做插屏强插、不在答题中途打断。
- 每天第一次正式挑战**不主动塞广告**（`FIRST_DAILY_NO_PROACTIVE_AD`），保护核心体验。
- 设最短广告间隔（30s）与休闲模式“每约 12 题最多提供一次总结”，避免诱导和被平台限流。
- 广告**只在完整观看后发奖**；未开通流量主时用模拟广告兜底，开发和冷启动全程不被变现能力卡住。
- 刻意**不做**金币/商城/道具付费/PVP 赌注等重系统：既超出当前规格、显著增加开发与合规成本，也会稀释“轻松学知识”的定位。先用最小可行的广告模型验证 eCPM 与留存，再谈加码。

收入成立的关键路径是：**日活 ×（挑战参与率 → 失败率/求知欲 → 广告点击率 → 完整观看率）**。因此产品优化重心是“让人多玩几天”，而不是“单次多弹广告”。

## 5. 成本与架构决策

- **原生 Canvas + 无引擎**：知识答题是纯文本/卡片 UI，自研轻量内核即可覆盖，包体小、加载快、无授权费与学习成本，也规避引擎版本维护。
- **本地优先**：进度、错题、收藏、掌握度全部本地存储，离线可玩；题库纯文本直接进包（当前 100 题仅几十 KB 量级，距主包 4MB 上限很远），不做远程题库与 CMS。
- **云开发延迟启用**：排行榜必须云端权威（防作弊），但开发期和上线初期不花固定钱，先用免费额度；开关化，临近上线一键开启。见 [CLOUD_AND_ADS.md](CLOUD_AND_ADS.md)。
- **防作弊放在服务端**：客户端只做体验层自检，真正的重算/去重/限频/只留最佳都在 `submitScore` 云函数；库表对客户端只读权限关闭。

## 6. 内容策略（比代码更决定成败）

- MVP 题库目标 500、稳态目标约 840；当前先交付 **100 道高质量样板题**，把字段、校验、解析与记忆点范式立住。
- 知识点是“本体”，题目是“表象”：扩题优先做“**同一知识点 × 多个生活场景**”，这样“间隔后换一道同知识点题复测”才真正成立（当前多数知识点仅 1 题，是下一阶段的首要内容工作）。
- 每道题必须有**正确答案 + 易懂的为什么 + 一句可转述的记忆点**，杜绝只有对错、学不到东西的“水题”。
- 选题坚持“有用、日常、可执行”，规避需要专项资质或争议性的内容（医疗诊断、投资荐股等）。

## 7. 数据指标（埋点已预留，二期接上报）

- 拉新/规模：DAU、新增、分享进入占比；
- 留存：次日/7 日留存、连续学习天数分布（核心北极星候选：**完成至少 1 局挑战的次日留存**）；
- 学习深度：人均答题数、正确率、错题复测通过率、掌握度提升、收藏/错题使用；
- 挑战漏斗：参与率 → 完赛率 → 平均正确数/得分 → 失败后“看广告再战”率；
- 变现：激励视频请求/曝光/完整观看/发奖、人均广告次数、ARPU；
- 成本：云函数与数据库资源点消耗（对照免费额度设预警）。

## 8. 迭代路线（建议）

1. **V1（本次交付）**：双玩法 + 掌握度 + 错题收藏成就 + 云端防作弊框架 + 广告框架 + 100 样板题，可直接真机试玩、可走通上线流程。
2. **V1.1 内容**：题库扩到 500（优先补齐“一知识点多场景题”），题目按难度/年龄更好分层；建立简单的“题目反馈（报错/无用）”收集。
3. **V1.2 上线与变现**：开云开发、过审、开流量主、配广告位；接埋点上报，跑真实漏斗与资源点成本。
4. **V2 增长**：成绩海报/分享卡片（“今天第 N 名/我又知道了 X”）、好友轻对比（不做强 PVP）、每日题“明日预告/连续打卡徽章”。
5. **V2.x 精细化**：按掌握度做个性化出题与复习提醒、薄弱分类专项；内容可运营化（在有数据验证后再评估是否值得上远程题库）。
